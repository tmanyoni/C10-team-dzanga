Data

Files are downloaded from the Kaggle competition
"Agricultural Extension RAG - Smart Retrieval for Farmers".

Run: python download_data.py

This fetches the five CSVs into data/raw/. Requires a Kaggle API
token at ~/.kaggle/kaggle.json.
